# Ink Heist website

Public site for **Ink Heist** (Turkish: *Çiz & Çal*), a real-time 1v1 drawing game for iPhone and Android.
Served with GitHub Pages: home, privacy policy, support and account deletion pages, in English and Turkish.

Pages are generated by `tools/gen.py` (`python3 tools/gen.py .`); styles are in `style.css`.
Fonts: Paytone One and Kalam, SIL Open Font License 1.1 (see `fonts/`). All art is original to the game.
